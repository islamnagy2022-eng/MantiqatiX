# خطة ظهور النسخة الجديدة V6 — إطلاق عام على مراحل

**التاريخ:** 6 نوفمبر 2026  
**الهدف:** إظهار تجربة AI Studio V6 بأقصر مسار آمن، ثم نقلها إلى الصفحة الرئيسية بعد قبول نسخة المعاينة.

## القرار التنفيذي

نطلق على مرحلتين، ولا ننتظر اكتمال كل وحدات المنصة:

1. **V6 Public Preview:** الرئيسية، الدليل، البحث، التخصصات، صفحات النشاط، الكتالوج العام والاتصال.
2. **V6 Root Cutover:** بعد قبول Preview، تصبح V6 الصفحة الرئيسية، مع إبقاء الموقع الحالي مؤقتًا في \`/legacy/\` ومسار رجوع واضح.

الموقع الحالي يبقى مستقرًا كما هو أثناء تجهيز Preview. المالية والمدفوعات وSMM وبقية الوحدات ليست شروطًا لإظهار الدليل العام.

## بعد الظهور — ترتيب الوحدات

1. ملف النشاط والكتالوج: قراءة ثم كتابة الملف والمنتجات والأسعار عبر Edge/RPC الحالية مع اختبارات tenant/business/branch.
2. مساحة صاحب النشاط: اختيار النشاط والفرع، الموظفون، صلاحياتهم، الاشتراك وسجل العمليات.
3. Super Admin: \`catalog-platform-admin\`، الأنشطة والعضويات والموافقات والتدقيق.
4. الطلبات والتشغيل: idempotency، الحالة، الفروع والمخزون.
5. المالية والدفع: دفتر الأستاذ والمحافظ والتسوية والاشتراكات وPaymob بعد عزل ومطابقة مالية.
6. CRM والتسويق والدعم وSMM وباقي القطاعات، كل وحدة خلف بوابة مستقلة.
