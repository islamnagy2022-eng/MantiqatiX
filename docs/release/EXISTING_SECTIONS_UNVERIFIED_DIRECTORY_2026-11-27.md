# Existing Sections for Menoufia Listings

This change removes the dedicated Menoufia catalog entry point and its blank 600-row intake template. Menoufia is handled only as a geographic filter in the same existing activity and medical sections and canonical taxonomy used by the rest of the platform.

- Category totals follow the active governorate/area filter.
- Existing unverified businesses and published, unclaimed directory records remain in their normal category and retain the visible unverified label.
- New admin records use the existing functional group and activity-category selectors and start as hidden drafts.
- This UI change does not import third-party directory data, alter production records, or change a record's verification state.
- Public unclaimed listings remain subject to existing source-rights, publication, and consent gates.
